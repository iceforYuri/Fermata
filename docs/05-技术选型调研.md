# 05 · 技术选型调研（2026-09-18）

> 状态：调研完成，待拍板
> 评估标准来自本 app 的真实形态：**重前端轻后端**——UI 负载很小（数百元素、1Hz 计时），真正的性能风险只有**模糊合成**与**冷启动**；选型标尺是排版保真度、玻璃效果成本、系统集成、内存包体、AI 协作杠杆。

## 需求清单（评估基准）

- Windows 10/11 优先；无边框自绘标题栏、置顶开关、托盘
- 排版优先 + 大量中文：精确字阶（28/15/12.5/12px）、等宽数字计时、可变字体、clamp 的栏宽
- 效果：**页内** backdrop blur（液态玻璃/高斯模糊弹层）、60fps 环倒计时、渐褪动画；窗口级 acrylic/mica 为可选加分
- 系统集成：全局热键、前台窗口追踪（WinEventHook）、空闲检测（GetLastInputInfo）、toast、自启
- 数据：SQLite local-first（已定）
- 目标：内存 < 150MB、快启动、小安装包；单人 + AI 结对

## 候选对比（2026-09 现状）

| 栈 | 排版与玻璃 | 系统集成 | 内存/包体 | 主要风险 |
|---|---|---|---|---|
| **Tauri 2.11** | ★ Chromium 全保真 CSS（backdrop-filter / tabular-nums / CJK DirectWrite 最佳）；mica/acrylic 经 window-vibrancy | 官方插件：热键/托盘/自启/toast/窗口状态；空闲+前台钩子约 50 行 Rust（windows crate） | ~10MB 安装包，内存轻松达标 | 透明窗口路径有已知 bug（黑块/白闪 #15947 / #10318）——**我们的玻璃是页内效果，不需要窗口透明，可绕开** |
| **Electron 44** | 同 Chromium，全保真；无 mica/acrylic API，透明窗口不可缩放 | **最强**：powerMonitor 空闲检测内置、get-windows（维护中）管前台、热键/toast 全内置 | ~100MB+ 起步，150–300MB 内存——**超标** | 内存与包体 |
| **WinUI 3**（WinAppSDK 2.5.1） | 原生 acrylic/mica + DWriteCore 中文极佳 | P/Invoke 三件套 trivial；MSIX 可绕 | 达标 | 动能风险（"WinUI 3 is dead"风波后转开源开发）、XAML API 换代、**AI 语料最少**、仅 Windows |
| **WPF（.NET 8/9+）** | 中文排版极佳；**BlurEffect 是 CPU 软渲染**，60fps 玻璃不可行；DWM acrylic 靠未公开 API hack | P/Invoke trivial | 达标 | 无 GPU 模糊路径——效果不达标，不推荐 |
| **Avalonia 12.1** | Skia 渲染，中文略逊原生；窗口级 AcrylicBlur/Mica 有（TransparencyLevelHint）；**页内模糊只有实验性 ExperimentalAcrylicMaterial**，无 backdrop-filter 等价物 | P/Invoke；无内置全局热键 | 达标 | 页内玻璃要手写效果，工程量大 |
| **Qt 6.11 QML** | MultiEffect 单遍 GPU 模糊可行，中文成熟 | C++ 原生，但全局热键要平台代码 | 优秀 | **闭源收费/义务**（LGPL 动态链接义务或商业许可）；AI 协作杠杆最低 |
| **Flutter (Win)** | Impeller 3.47 起默认，BackdropFilter 改善但仍是引擎最贵路径 | window_manager 迁移中、flutter_acrylic 停更——**社区胶水质量参差** | ~25–40MB | 桌面集成为社区包，维护不稳 |
| Wails v3 / Neutralino / Compose MP / MAUI | — | — | — | 分别为：beta 未生产就绪 / 原生 API 太薄 / 无页内模糊+JVM / Windows 上是 WinUI 3 套壳，无意义 |

## 结论

**推荐 Tauri 2（Rust + WebView2）**：我们的验收线（排版、液态玻璃、中文）恰好就是 Chromium CSS 的满血区；官方插件盖住托盘/热键/自启/toast；内存与包体宽裕达标。唯一要守的规矩：**窗口保持不透明（Win11 可选 mica），玻璃全部做在页内**——Tauri 在 Windows 上的已知 bug 都集中在透明窗口路径，我们恰好不需要它。

**无悔备胎：Electron**——系统集成最全（空闲检测内置、get-windows 管前台窗口），若 Rust 成为障碍可承受约 2 倍内存换省心。

**C# 三兄弟的裁决**：WPF 输在 GPU 模糊；WinUI 3 技术上最"原生"但动能与 AI 语料双风险；Avalonia 是最好的非 web XAML，但页内玻璃要手搓效果——若将来"账号页/多端"诉求变强可重估。
