# 04 · 系统层 —— 切换浮层与休止符弹窗

> 状态：v0.3（2026-09-18，Round 10–11 定案：浮层 + 休息页样式）
> 定位一句话：主窗不置顶、无窄栏，用户工作时的全部触点就是这两个浮层——前者管切换，后者管节律。

## 共通规格

- 无边框、置顶、圆角卡片（与主窗卡片同语言），暖色两主题
- 切换浮层**要**键盘焦点（用户主动唤出）；休止符弹窗**不抢**焦点（系统发起，鼠标可点）
- 切换浮层 Esc = 收起；休止符弹窗 Esc = ✕ = 进入休息

## 切换浮层（任务版 Alt+Tab）

> 一句话：Alt+Tab 切的是窗口，它切的是"你正在做的事"——主窗的遥控器。

### 唤出与形态

- 全局快捷键唤出（默认建议 Alt+Q，设置可改）；居中命令面板式浮层，约 520px 宽、最高 60vh；失焦自动收起

### 结构（自上而下）

1. **输入行**：过滤与新建二合一——打字即筛；无匹配项时首条变为"新建「xx」并切换"
2. **当前进程**（固定顶部，仅作上下文）：色脊 + 标题 + 运行中标记 + **时间环读数副本**（剩余分钟）
3. **等 AI 组**（带小标记，排前）
4. **挂起队列**：色脊 + 标题 + 断点一句话 + "挂 23m" 老化

### 键位

- 数字键 1–9 直选；↑↓ 导航；Enter = 切换；Esc = 收起；A 键 = 切换选中行的「等 AI」状态

### 断点内嵌流程（2026-09-18 定）

- Enter 切换瞬间，输入行**原位变形**："给「旧进程」留个断点（可空）↵"，**预填当前生效断点**（自动断点或钉住的手动断点，v1.1）
- 再按 Enter 确认走人；Esc 取消整个切换——两次回车 = 一次完整切换，断点可留空

## 休止符弹窗

### 触发（2026-09-18 定）

- 时间环走满 **或** 连续工作超阈值（ADR-0002）
- **软模式**：触发时入队，等三个自然间隙之一再弹——切回主窗 / 打开切换浮层 / 任务完成；环走满到弹窗出现之间计时照常（在流里不打扰），环呈超时态
- **硬模式**：到点即弹
- **弹窗出现即暂停计时**（默认休息态）——时间的默认值是"不计"，继续由用户显式开启

### 形态（2026-09-18 定）

- 居中小卡约 420px，无边框置顶**不抢焦点**，鼠标点击即可操作
- 标题写明触发源："时间片走满 · 第 47 分钟" / "已连续工作 92 分钟"
- 三个主按钮：**暂不休息**（恢复计时、环重置满环）/ **休息**（进入休息态）/ **翻下一篇**（展开挂起老化列表前 5 条，点选即切换）
- **无超时、不自动消失**——一直显示，直到用户做选择或手动关闭
- **✕ 关闭弹窗 = 进入/保持休息态**（不是"忽略"）——保守默认：没被确认的时间不计

### 休息的形态（2026-09-18 定，桌面优先）

- 点休息后弹窗原地变**休息态**：正计时显示已休时长（"休息中 · 4:32"）+ "我回来了"按钮
- **休息无固定时长、无自动结束、无主动提醒**——人在电脑前，弹窗自己会等，不发"回来吧"式通知（桌面端，非移动端推送逻辑）
- 恢复计时**只有三条路**（全部显式）：
  1. 弹窗里点"暂不休息" / "我回来了"
  2. 回主窗：**休息页**（霸占 tab 1）点「继续」——设计见 01-进程页.md
  3. 切换浮层直接切到别的进程——显式选新进程 = 显式开工，等价"翻下一篇"
- ✕ 弹窗 = 保持休息（计时仍停着，主窗 tab 1 的休息页仍在等）
- 连轴转计数归零；环暂停
- **休息态双渲染**：休止符弹窗与 tab 1 休息页是同一状态的两种视图，动作等价（"我回来了" = 「继续」）

## 微弹窗族

- **断点微弹窗**：主窗内直接点击挂起行切换时的兜底——行旁小卡输入断点（可空回车），语义与切换浮层的内嵌流程一致
- **空闲回归确认**：系统空闲超阈值后回来，小卡问"刚才还在做「xx」吗？"，是 / 否；30 秒超时默认"是"

## 开放问题

2. 软/硬模式仅剩"弹窗时机"差异（间隙弹 vs 立即弹）——设置页定稿默认值
