# 01 · 进程页（Tab 1）—— 一天的版面

> 状态：草案 v0.1（2026-09-18）
> 定位一句话：常驻主页面。整个 app 在"排今天的版"，本页就是版面本身。

## 全局框架（适用于三个 tab）

- 单窗口，长宽比 1:1 ～ 16:9 自适应；三栏共存（左稿库 + 中进程 + 右详情）需要偏宽一端
- 顶栏（v1.2 修订）：居中**无边界 morph 导航**（弹簧 pill 模型；参考组件文档已因版权移除，弹簧参数 response 0.42s / zeta 0.86 已落在 TitleBar）——无容器底、无分隔线；未选中=小图标，选中=弹簧 morph 展开为"图标+文字"（pill 染底极淡）；hover 未选中项微光晕染底；切换时先收起两侧面板、再横滑
- **不做窄栏态 / 独立调度条**（2026-09-18 定）：主窗的可见性改由「窗口置顶开关 + 系统层浮层」承担
- **主窗口默认不置顶（2026-09-18 定）**：主窗是"回来看版面"的地方；工作时的可见性交给切换浮层（含当前进程与环读数）和休止符浮窗；置顶做成设置开关
- 面板语言：**推拉，不弹窗**。内容永远在场，面板只是版面重排
- **主题（v1.1 修订命名）**：两套——亮·淡暖 / 暗·工作台；纸感报纸风为后续主题候选
- **中列内容宽度（2026-09-18 定）**：区间 + 窗口占比——clamp(窗口宽 × 约 45%，480px ～ 720px)，原型阶段再调参

## 视觉规格（Round 2 定案，2026-09-18）

- **配色基调**：暖色感极简；**无全局强调色**——颜色属于「色标」维度（2026-09-18 定）：**7 种颜色用户自选，语义用户自定义、无预设级别**；色板为暖调家族、两主题各调明度（原型定稿）；色标不影响排序（颜色是属性，不是排序键）
- **底色**：亮·淡暖 #FCFBF7（v1.1 修订：原 #FAF7F2 偏黄，提亮降黄）；暗·工作台暖炭 #26221E
- **色标锚点（2026-09-18 定）**：确认条全饱和填充 + 行边框同色 + 主体同色淡染底（约 12–15% 不透明度）；时间环继承色标色；挂起老化时三者一起渐褪；完成入已完栏时色标褪去（沉降入素色）；完成档案内的行保留色脊（书架隐喻收尾）。边框粗细原型定稿
- **字体栈**（v1.1 修订）：正文打包 MiSans（Regular/Medium/SemiBold），回退 Noto Sans SC → Microsoft YaHei UI → system-ui；**数字一律等宽**（MiSans tnum 特性，计时跳动不抖）；标题无衬线加粗；暗色主题整体更"等宽感"
- **进程行形态（2026-09-18 定）**：卡片——圆角 4–6px、1px 色标色边框、同色淡染底、行间纯留白 8–12px；折线仍是 1px 横线，卡片是它的内容物
- **行高阶梯（2026-09-18 定）**：报头 ~28px / 已完栏 ~40px / 活跃行 ~112px（由环 64 + 上下各 24 顶出）/ 挂起行 ~64px / + 号新建 ~40px / 行间距 8–12px；断点超长单行截断，全文进详情栏
- **字号阶梯**：活跃标题 ~28px 半粗 → 当前步骤（导语）~15px medium 全前景色 → 挂起标题 ~15px 常规 → 累计/时长 ~12.5px → 报头/已完栏 ~12px；层级靠字号 + 字重 + 透明度（色标颜色是分类维度，不作层级手段）
- **折线**：1px 细线 + 上下留白不对称（完成区紧凑、挂起区呼吸）——"线要存在，但只许细"
- **时间环形态**：活跃行右端，直径 ~64px；环内显示剩余整分钟，悬停 mm:ss；最后 5 分钟缓慢呼吸；环色 = 该进程的色标色
- **玻璃语言边界（2026-09-18 定）**：液态玻璃 / 高斯模糊只用于"盖住自家内容"（休息页、完成档案）；对外浮层（休止符弹窗、切换浮层）用实心暖卡——玻璃会把别家内容 blur 进来当噪音

## 术语速查

| 词 | 含义 |
|---|---|
| 折线 | 版面的水平分界：上方 = 已完（已完栏），折线上 = 活跃进程，下方 = 挂起队列 |
| 断点 | "做到哪了"一句话；默认=自动断点（步骤栈顶未完成步骤），手动写入则钉住（v1.1） |

| 休止符 | 时间环走满或连轴转超阈值时触发的休息/切换提醒 |
| 付印 | 一天结束的归档/导出动作（后续版本） |

## 页面结构（自上而下）

1. **报头**：日期·星期（格式"9 月 18 日 · 周五"）+ 今日累计 xh xm，一行小字；与已完栏同属顶部弱化区——2026-09-18 定
2. **已完栏（已完折叠块）**：中列顶部一行弱化横条——**亮主题偏灰、暗主题偏褐**（弱化一档，不做反色，2026-09-18 修订）；"今日已完 · N 件 · 总时长"。点击弹出**完成档案子页面**（见"子页面 · 完成档案"）
3. **活跃进程**：折线上的"头条"
4. **挂起进程行队列**
5. 新建进程入口：中列底部一行式 + 号（回车即建、落挂起队列尾部）——2026-09-18 定
6. **空状态**：今天无进程时不留白——一句排版好的引导语 + 两个动作入口（稿库拖入 / + 号新建）——2026-09-18 定

## 进程行解剖（两段式，已定）

```
[ 确认条 | 标题大字 / 断点小字 ……………… 累计用时 xh xm ]（活跃行另带时间环）
```

- **确认条**：很窄（约 28~40px）。点击 = 标记完成、越过折线收纳折叠
  - **误触防护（2026-09-18 定，方案 B）**：完成后出现 3 秒撤销 toast——3 秒内再点一次即撤销；不撤销则折入顶部完成档案。档案"重新打开"仍是最后兜底
  - 条目（步骤/断点条）hover 出 × 删除（v1.2）
- **主体**：
  - 进程标题大字：活跃进程字号最大，挂起行逐级缩小（字号即层级，不用缩进树）
  - **导语槽（v1.2 统一栈口径，ADR-0005）**：断点与步骤统一为一个栈（步骤=可勾选条目，断点条=▸ 便签不可勾选）；写断点=压栈顶；导语=栈顶条目；活跃行就地勾选框只在栈顶为步骤时出现；栈空显示淡字"未留断点"。排版按"导语"：~15px medium 全前景色
  - **就地勾选（2026-09-18 定）**：活跃行的当前步骤常显勾选框（挂起行 hover 浮现）；勾选 = 完成该步骤，小字跳到下一个未完成步骤（轻微推进动画）——推进步骤不必打开详情栏
  - 尾段：**当天累计用时（xh xm，低视觉权重）**，所有行统一显示；分段明细只进右栏详情
- 挂起行附加**老化信号（2026-09-18 定）**："挂起 23m"小字；透明度 1 → 0.45 按挂起时长对数渐褪（前快后慢）；不加警示图标——警示交给切换浮层与休止符页；**hover 解除褪色**、光标手型——注意力的光照到哪行，哪行醒过来
- 挂起行双动作分区：点击 = 切换、拖动 = 排序；拖动 4px 位移阈值才启动，防误触——2026-09-18 定。v1.2：拖过折线到活跃位=切换（松手即换），拖拽中后续行弹性挤位（FLIP+弹簧）+ 落点虚影（半透明轮廓卡）；活跃位虚影直接覆盖原活跃行位置（原任务不下移），松手后原活跃下沉回队尾、断点卡从其下方展开。**v1.2.4 统一插入预览（先塌陷后开缝）**：拖起即按最终序对各行做 transform-only 弹簧归位——被拖行原槽由后续行补位（塌陷），插入位撑开一道缝留给虚影（开缝），不再整体后移；稿库拖入与进程行拖拽共用同一套几何（`src/components/dnd.ts`）

## 活跃进程专属

- **时间环（页面里最显眼的计时）**：时间片倒计时，回答"还能专注多久"
  - 环属于本次进程会话：切换进程即重置满环，提前切走记一次"未完成时间片"（入日志）
  - 环走完 → 触发**休止符页**（系统层）；休止符从"突袭"变"看得见它走近"
  - **双触发（2026-09-18 定案，ADR-0002）**：休止符 = 环走满 **或** 连续无休息工作超阈值（默认 90 分钟，设置可调）——环管单进程节律，连轴转计数管"该休息了"
  - 暂停时环停走、变暗
  - 默认时长来自设置；在环上拖/滚轮直接调——待定
- **累计用时 xh xm（不显眼）**：当天该进程总投入，回答"今天投了多少"。两个计时一个管节律、一个管账本，视觉权重刻意分开
- 计时规则：**置顶即计时**。拖上折线 / 点击切换的瞬间开始，下一位上来自动停
- 开始 / 暂停按钮（手动覆盖）

## 推拉面板

### 左栏 · 稿库（计划）

- **常驻细 rail（v1.1 修订）**：进程页左缘约 28px 细栏，仅一个方向箭头（收起 › / 展开 «），无图标无文字；hover 整条微亮 + 手型；点击展开为面板（左划入、中列右移），再点 rail 或点中列任意处收起。**rail 只存在于进程页**，顶栏不再有稿库入口。面板**固定宽度（约 300px）**——保中列行长稳定。rail 收起时其右侧版缘常驻淡色小字"← 稿库"（~30% 透明度），展开即隐（v1.2）
- **条目结构（2026-09-18 定）**：标题 + 可选预计时长；分「今日剩余 / 明日草稿」两组；行内小操作（删除、直接完成）。稿库是库存，不是表单
- **条目形态（2026-09-18 定）**：单行 ~44px（标题 15px + 右端"预计 45m" 12px）；组头 12px 小字；hover 浮现 ✕ / ✓ 小图标 + 抓取光标；条目 v1 无色标
- 与统计页待办编辑区双向同步（同一数据源）
- 拖一条进中列 = 立即成为进程（v1.2.4：**中列整列都是感应区**，dragover 实时按光标 y 换算插入位、开缝出虚影；Esc/拖出中列取消）：落队列某缝位=挂到该位；推过折线到活跃位=激活语义——虚影覆盖活跃行，松手断点卡从原活跃行下方展开（可空，Enter 确认 / Esc 取消整个切换），与点击切换同待遇；**空板拖入（任意位置）= 直接激活**，无断点卡（F3：没有旧进程可留断点）——2026-09-18 定，v1.2.4 修订

### 右栏 · 详情（点击进程唤出）

- 从右向左滑入、中列左移，此时中列与右栏**约对半分**。不对称是刻意的：左栏是"扫一眼的库存"，右栏是"坐下来干活的工作台"，后者配得上半版
- **模块与顺序（2026-09-18 定，按信息层级排，不按编辑频率）**：标题作栏头（点击可编辑）→ 断点（最高频，最显眼）→ 步骤清单 → 分段时长（自动记录、只读 + 可加备注）→ 个人记录（自由文本，沉底）
- **色标（2026-09-18 定）**：详情栏内一行 8 格（7 色 + 无色），点击即换；新建默认无色
- **双态样式（2026-09-18 定）**：非修改态 = 纯排版文字，无任何表单痕迹；点击文字**原地变输入框**——同字号、同位置，1px 色标色下划线是唯一编辑指示；Enter/失焦提交、Esc 还原、无保存按钮（失焦即落盘）。编辑态是排版态的原地变形，不是另一个界面
- 统一栈（v1.2 修订，ADR-0005）：**新条目录顶**（步骤与断点条同栈）；勾选框步骤未完成=空圈，勾选 = 划线 + 变淡原位不沉底；断点条无框、▸ 前缀、可 ×；**顶部**常驻"+ 添加步骤"幽灵行；可拖拽重排（栈序只是插入默认）
- 分段时长：默认折叠为一行摘要（"今日 3 段 · 47m"），点开逐段列表，每段可加备注
- **内联编辑，不用弹窗**：以上模块全部就地改
- 互斥规则：窗口接近 1:1 时，右栏唤出自动收起左栏；16:9 宽屏允许三栏共存（左 300px + 中右对半）

### 子页面 · 完成档案

- 入口：中列顶部的已完栏
- 形态：浮层子页面，**版式与中列相同（进程行解剖一致）但范围更小**，周边高斯模糊
- 收起：点击模糊区域或再点暗色栏
- 档案内的行支持**重新打开**：进程回到挂起队列尾部——确认条误触之外的最后兜底
- 档案内的行保留色脊（书架隐喻：完成的书立在架上）——2026-09-18 定

## 状态机（草）

```
挂起 --拖上折线/点击--> 运行 --确认条--> 完成（折叠入档案）
完成 --档案内重新打开--> 挂起
挂起 --拖回稿库?--> 计划          （待定）
运行/挂起 --一键标记--> 挂起·等 AI（2026-09-18 定：做）

「挂起·等 AI」细则：不褪色（在等机器，不是被遗忘）+ 断点小字前的小标记；老化时长照算；切换浮层里排前；标记入口在切换浮层与详情栏各一个
```

## 休息页（休息态霸占本页，2026-09-18 定）

- 进入休息（休止符弹窗点"休息"或 ✕ 弹窗）时，**tab 1 整页被休息页取代**；tab 2 / 3 可正常切换
- 内容与样式（Round 11 定，2026-09-18）：**液态玻璃整页**（backdrop blur + 高光描边——模糊是"遮盖"语言，与完成档案同族：休息时版面在玻璃后面等着）；纵向居中：**灰色满环 + 中心 ▶ 图标 = 「继续」按钮**（环即按钮，hover 亮起；Enter 等价）→ 大字"休息中 · 12m"正计时（~40px 等宽）→ 触发源回执小字（"时间片走满 · 第 47 分钟"）→ 底部小字今日累计 + "Alt+Q 可切进程"
- **「翻下一篇」不上休息页**（切换交给浮层）——休息页只回答"回不回来"
- 顶栏 tab 1 标签带**休止符小符号**（SVG 绘制——休止符字形在字体栈里覆盖不稳），休息态在 tab 2 / 3 里可见
- 点「继续」= 恢复计时、环重置满环、版面复原；Esc / Enter 同「继续」；▶ 为 SVG 三角形（非字符）；环下常驻"继续"小字（v1.2）
- 与休止符弹窗是**同一休息态的两种渲染**：弹窗"我回来了" = 休息页「继续」；✕ 弹窗后休息页仍在等
- **手动暂停 ≠ 休息**：行内暂停/开始按钮照旧（用户自己按的暂停，行内恢复即可）；休止符发起的休息才霸占

## 系统层（不属于任何 tab，服务于本页流程）——完整设计见 docs/04-系统层.md

- **切换浮层**：全局快捷键唤出，进程版 Alt+Tab；内嵌断点输入（选中 → 留一句话 → 回车走人）
- **休止符提醒**：触发条件 = 时间环走满 **或** 连续工作超阈值（ADR-0002）；**无超时**，弹窗三选（暂不休息 / 休息 / 翻下一篇）+ 挂起进程的老化情报。自定义无边框置顶浮窗、不抢焦点，细节见 docs/04-系统层.md；Windows 系统通知为兜底
- **断点微弹窗**：仅在非浮层路径切换时兜底
- **空闲回归确认**：系统空闲超阈值后回来，问"刚才还在做这个吗？"
