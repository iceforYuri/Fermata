# 以"挂起/恢复调度"为产品核心，排版是呈现层

最初设想是"排版精美的日程应用"，但真实痛点是 AI 等待导致的多任务上下文遗忘：切走时忘记之前做到哪。因此产品的内核定为任务的挂起/恢复调度器（进程状态机 + 断点 + 计时 + 休止符），报纸式排版只是这层调度数据的呈现方式。设计顺序上，调度行为先定，视觉后定；排版做得再好不能替代调度正确性。

## Considered Options

- **日程排版工具**（Notion/手账式）：被否——美化一天并不解决"忘记做到哪"，且该赛道拥挤。
- **挂起/恢复调度器**（选定）：直接命中痛点，且桌面端独有的窗口焦点/空闲检测能力恰好服务于它。
