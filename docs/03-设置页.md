# 03 · 设置页（Tab 3）—— 工具间

> 状态：v1.0（2026-09-18，Round 12 定案）
> 定位：低频页面。**第三个 tab（2026-09-18 定）**——留在左右滑动序列内：直观、三页对称，且为将来拓展账号页留位（顶栏可长出第四页）。

## 页面结构（Round 12 定，2026-09-18）

- **单列滚动**（居中 measure，与进程页 / 统计页同版面语言）
- **左竖分组导航**（v1.2 修订，~150px）：组名竖排、淡化右边线、当前组 1px 下划线、hover 微亮；点击平滑滚动到对应分组，scroll-spy 高亮当前所在组；窗口宽度不足时导航隐藏、内容独占
- 分组标题 = 锚点，组间留白分隔
- **控件语言 = 双态**：非修改态是一行排版好的文字（"时间片长度　45 分钟"），点击原地变形为 stepper / 输入（1px 下划线唯一指示），Enter/失焦提交、Esc 还原、无保存按钮——全 app 无一处传统表单

## 分组

### 时间片与提醒

- 时间片长度（**默认 45 分钟**，2026-09-18 定；修改只影响下一个环，当前环不动）
- **连续工作阈值**：无休息连续工作 N 分钟也触发休止符（默认 90 分钟，2026-09-18 定，ADR-0002）
- 休止符模式：**软**（自然间隙才弹：切回主窗 / 打开切换浮层 / 任务完成）/ **硬**（到点立即弹）——无超时自动行为，两模式只差弹窗时机；默认软
- 提醒样式：**自定义应用内弹窗**（无边框、置顶、不抢焦点，2026-09-18 定，细节见 docs/04-系统层.md）；Windows 系统通知为兜底

### 计时

- 空闲检测阈值：无键鼠输入 N 分钟 → 自动暂停（**默认 5 分钟**，2026-09-18 定）
- 空闲回归确认开关

### 外观与排版

- 字体、字号阶梯（大字/小字层级）
- 版面密度（行距 / 卡片间距）
- **主题（2026-09-18 定）**：可换主题，初期两套——亮·极简现代 / 暗·工作台；纸感报纸风为后续候选
- **色标（2026-09-18 定）**：7 色暖调、语义用户自定义；色板原型定稿；后续：色标命名、自定义色板、染底浓度开关（淡染方案已采纳）
- 窗口置顶开关（默认关，2026-09-18 定）
- 左栏固定宽度可调

### 快捷键

- 切换浮层的全局热键（核心，必设；默认 **Alt+Q**，2026-09-18 定）
- 其余后补

### 数据

- （后续）付印 PDF
