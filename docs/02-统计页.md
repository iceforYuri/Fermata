# 02 · 统计页（Tab 2）—— 复盘与明日之稿

> 状态：草案 v0.1（2026-09-18）
> 定位一句话：看今天数据的地方，也是写明天计划的地方。晚间入口。

## 页面结构（自上而下，2026-09-18 依参考图示例修订；原始参考图已因版权移除）

**视角胶囊（2026-09-18 定）**：页面顶部居中的小开关胶囊 [年 | 月 | 日]，切换本页主视角（~160ms 交叉淡化 + 轻微纵向位移）；进入统计页默认 = **月视角**（大环与当天视图锚定今天）。**钻取联动**：年点月环 → 月视角（切到该月）；月点日期格 = 选中不跳页；双击日期格 → 日视角（该天）；**日视角改为纵向滚动（v1.1；v1.2 去 mandatory 吸附改自由滚动）**：按天懒加载，上界=最早有记录的日期、下界=今天，吸顶日期标签点击回月视角，滚动内容顶/底缘淡出遮罩；**滚动条隐藏（v1.4：滚轮 + 月视角点日期直达为导航路径；容器 `overflow-anchor:none`——原生滚动锚定与 prepend 手动补偿会双补偿把视口顶到最底，快速滚轮下复现过）**；视角胶囊固定不随滚动；**进场定位（v1.4 定）：锚日大日期标底缘距窗口底 40px（token `--day-enter-gap`），底部垫高与之同值——滚到滚动尽头即今天的进场位置**；**月视角不滚动**，换月仅两条路——年视角点月环、「回到今天」；切换视角保留锚点（滚动模型下滚动位置即锚点，静止后联动）。**两个"日"入口并存**：月下方当天视图 = 清单视角（做了什么），日视角 = 时间轴视角（什么时候做的）

**布局（2026-09-18 定）**：纵向单列，居中一条 measure，与进程页同排版语言；宽屏并排留作将来优化

1. **月历（月视角主体，居中不滚动）**：整月日历，每个日期格内一枚**迷你日环，按色标聚合**（小尺寸下按进程切片不可读）——日历既是选择器也是数据；空日子一眼可辨
2. **大环（上下文相关）**：**每进程一片**（颜色 = 色标，图例列进程名 + 时长）；**默认锚定今天**，点选日期切换；"回到今天"一键。环旁核心数字：总专注 / 切换次数 / 最长单段
3. **当天视图**（日历下方，选中某天展开）：
   - **已做**：完成进程清单（沿用中列卡片语言）+ 各自用时
   - **进行中**：未完进程的进度与已投时长
   - **未做**：当天预定过计划但没动的
   - **计划编辑**：为该天制定 / 编辑 / 删除 / 直接完成计划，与 Tab1 左稿库同源
   - 挂起成本：每件挂了多久才被捞回 / 仍未捞回
4. **日视图（2026-09-18 定，原始参考图已因版权移除；v1.2.3 改 18×6）**：**18 列 × 6 行 = 108 格日网格**，每格 10 分钟、每列 6 格 = 1 小时；时窗 06:00–24:00（0–6 点不画，记 deviation）；横向刻标 = 单点时刻 6 / 12 / 18 / 24——6 对网格最左端（6:00）、12 对第 6|7 列分界、18 对第 12|13 列分界、24 对网格最右端；只保留下行（v1.2.2 用户定：上行冗余）；按列阅读（列内自上而下、列间自左向右，推定自参考图，原型对图校验）；有记录的时段沿阅读方向填**色标色圆圈串**（一段进程从起点格连续填充，无色 = 灰）；**悬停圆点 → 进程浮窗**（进程名 + 该时间格内占用起止 + 时长；区间钳制在格窗内、开口段钳到当下，v1.4；无断点行——纯数字自解释）；一格内多进程冲突时**占用率 ≥20% 者取前二、同一枚圆对角分半**（主导色右下、次者色左上，两半各悬停各显，v1.4）；空隙 = 留白（空闲/挂起空窗，本身是数据）；未来日期显示"尚无记录"；「等待 AI」分段 v1 实心、空心后置。**v1.4 填充规则：格的占用率（分母=格的 10 分钟）<20% 不画、20–80% 45° 斜半圆（段起点格=色在右下、段止点格=色在左上，参考图实测）、≥80% 全圆（仅当次者 <20% 时成立）；两阈值入 token（`--grid-min-share`/`--grid-half-threshold`）**。整格网格 6 行 × 64px，桌面单列一屏放下——回答"这一天的时间是怎么过去的"；每天单元=吸顶小日期签（滚过出现，点击回月）+108 格网格+右下大日期标（"23 mon"，数字 28px 半粗、星期 12px 小写，点击回月）；单元间距 72px；圆 26px、幽灵点 4px（v1.2.2）
5. **年视图（2026-09-18 定）**：12 月环网格（每格一枚月环，点月环下钻月视角）；**纵向滚动**、只显示有记录的年份范围；12 列堆叠条做切换备选

## 环状图配色（2026-09-18 定）

- **切片 = 进程，颜色 = 该进程的色标**（图例：进程名 + 时长）
- 无色标进程 = **中性灰切片**（2026-09-18 定）——灰占比本身是信号（"今天 65% 时间没分类"）；自动配色被否，颜色的语义契约不可破
- 月历迷你日环、年视图月环同规则缩放
- 视角胶囊 = 暖色分段控件，选中段染底 + 脊色高亮（与色标卡片同语言）；迷你日环在空日期上不画

## 计划的日期模型（2026-09-18 定）

- 计划带**预定日**属性；统计页点任意一天可为该天制定计划；Tab1 左栏照旧显示今天 + 明天两组
- **未做** = 该天预定的计划当天没变成进程也没完成
- **过去的日子**：进程记录只读；那天的计划仍可删除或"直接完成"——零时长计入该日，标记**「未计时完成」**
- 补记真实时长后置 v1.x——诚实口径优先于好看的数据
- 「未计时完成」的进程在日网格里不画圆圈（无时间锚点），只在当天视图清单出现

## 数据口径（与计时模型一致）

- 进程时长 = 进程位于折线上的期间 ∩ 系统非空闲
- 切换次数、挂起时长、时间片完成率全部来自事件日志
- **事件日志从第一天就记全**：切换 / 暂停 / 空闲 / 完成 / 断点内容——统计和以后的 AI 批注都靠它吃饭

## 核心闭环

```
晚上：看今天（数据）→ 写明天（计划）→ 存入稿库
次日：Tab1 左栏看到稿库 → 拖一条进版面 → 成为进程
```

后续版本（先把日志记全，界面后置）：周视图、付印 PDF 导出、AI 边栏批注。
