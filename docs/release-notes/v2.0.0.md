# Fermata 2.0.0

Fermata 2.0 是 Android 客户端首版，同时把桌面端的数据内核与同步能力收敛到同一套协议。

当前为发布候选，尚待真机验收；正式发布、标签与主分支合并尚未完成。

## 新增

- **Android 客户端**：Tauri Mobile + Kotlin Keeper；底部纯图标导航、稿库抽屉、进程详情底卡、长按菜单、拖拽排序、休息态与统计三视角。
- **跨端同步**：坚果云 WebDAV；gzip 整库快照与远端版本检测。首次接入冲突可选择方向；建立基线后，远端变更且本机也有修改时，先备份本机再采用远端。强制推送前备份远端，尚不支持实体级合并。
- **数据内核**：进程 / 计划 / 步骤 / 分段加入全局 uuid 与 updated_at，步骤采用软删除墓碑；Android 凭据使用 Keystore 加密，Windows 凭据保存在凭据管理器。
- **Windows**：保留报纸式版面、计时、休止符与统计能力；新增同步设置区。
- **移动端适配**：进程页、详情卡、统计年/月/日轮播、设置页双端适配、20 分钟粗粒度日网格与日网格占用清单。
- **产品文档**：双端 README、中文演示数据的 14 张新界面预览、Android 操作说明和同步备份恢复说明。[预览来源](../screenshots/release/v2/README.md)。

## 升级与安装

### Windows

使用 `publish/Fermata-2.0.0-setup.exe` 或 `publish/Fermata-2.0.0-portable.exe`。首次启动会自动执行 v6 数据迁移；升级前建议保留现有数据库备份。

### Android

使用 `publish/Fermata-2.0.0-android-arm64.apk`（Android 7.0+，arm64）。首次启动允许通知权限；在「设置 → 同步」中填写坚果云账号和第三方应用密码。首次接入时若两端都有数据，选择推送或拉取，覆盖方会先自动备份。

## 验证范围

- 内核测试：`cargo test`（21 项）。
- 前端类型检查：`tsc --noEmit`。
- Android 模拟器：构建安装、启动、建进程、详情卡、统计切换、设置同步区、休息态、完成档案。
- 真机待验：通知权限、息屏 30 分钟计时、通知栏暂停/继续、到点提醒、坚果云同步、冲突备份与接管。

## 已知限制

- Android 首版仅提供 arm64 APK，采用 sideload，不上架应用商店。
- 同步首版采用整库覆盖策略；实体级三方合并与事件并集属于后续版本。运行锁依赖网络和同步状态，不能保证离线两端互斥。
- 事件日志的逐 kind payload 完备性仍需在实体级合并前继续审计。
- 移动端 WebView 在某些模拟器上退后台会触发 Chromium onTrimMemory SIGILL，真机行为以实际设备为准。
