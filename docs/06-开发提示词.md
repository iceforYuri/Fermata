1. 读仓库根 `AGENTS.md`，然后按它给出的顺序读完 docs/ 全部文档与两张参考图；术语以 CONTEXT.md 为准。

3. 本目录 `git init`，首次提交把现有文档作为基线；此后每完成一个子任务提交一次。

## 五个阶段（每阶段：验收全勾 + 宪法七条自查 + 截图入库，才进下一阶段）

### P · PoC（技术门槛，最先做）

- Tauri 2 + Vite + React 起骨架，验证三件原语：
  1. `focusable:false` 的弹窗 `show()` 后**不抢焦点且鼠标可点**
  2. opaque 窗口内**页内 backdrop-filter 正常**（做一个休息页玻璃小样：灰满环 + "继续"）
  3. `global-shortcut` 注册 Alt+Q + `user-idle` 空闲回调（阈值 5 分钟）
- 任一失败：先修复；确属硬阻断 → 按 AGENTS.md 兜底条款切 Electron 并记录
- 产出：可运行空壳 app + `docs/screenshots/poc/`

### M0 · 数据内核

- SQLite schema：进程（状态机：挂起/运行/挂起·等AI/完成）、计划（带预定日）、色标、步骤、断点、分段时长、色板
- **事件日志 append-only**：切换、暂停、空闲起止、环走满/未走满、休止符触发与用户选择、休息起止、完成、步骤勾选——从第一天记全
- 验收：种子脚本可插入一周示例数据；用日志能查出"某进程当天累计、挂起了多久、时间片完成率、连续工作时长"

### M1 · 进程页（含视觉定稿）

- 按 docs/01 全量实现：报头 / 已完栏 / 活跃行（时间环 + 当前步骤槽 + 就地勾选）/ 挂起队列（老化渐褪 + hover 复活）/ 底部 + 号新建 / 空态 / 1px 折线
- 色标三件套（确认条脊 + 1px 边框 + 12–15% 染底）；详情栏与稿库的推拉；完成档案子页面（高斯模糊 + 重新打开）；休息页（液态玻璃 + 灰环即"继续"按钮）
- **先做一屏静态高保真调参**：把 tokens.css 定稿——色标 7 色具体值、染底浓度、边框粗细（这批"原型定稿参数"现在授权给你，按 AGENTS.md 审美方向定）
- 验收：与 01 视觉规格逐条对照；推拉 / 双态编辑 / 就地勾选 / 3 秒撤销 / 档案重开全部可用；置顶即计时与空闲检测接上真实数据

### M2 · 系统层

- 六原语接口 + 切换浮层（过滤/新建二合一输入行、当前进程上下文行含环读数、等AI 排前、1–9 直选、Enter 切换、**断点内嵌流程**、A 键标等AI）+ 休止符弹窗（触发源标题、三选、无超时、✕=进入休息）+ 休息页霸占 tab 1（tab 带休止符小符号）+ 空闲回归确认微弹窗
- 验收：Alt+Q 纯键盘 2 秒完成一次"切换 + 留断点"；休止符双触发（环满 / 连轴 90 分钟，可用日志快进模拟）；休止符弹窗在被验证**绝不抢焦点**（用第二个窗口打字自测）

### M3 · 统计页

- 三视角胶囊（年/月/日，锚点联动钻取）+ 月历迷你日环（**色标聚合**）+ 大环（每进程一片、颜色=色标、无色=灰切片、默认锚定今天）+ 当天视图（已做/进行中/未做/计划编辑）+ 96 格日网格（15 分钟/格、列刻 0/6/12/18、圆圈串、悬停浮窗、空隙即数据）+ 年视图 12 月环网格
- 验收：用 M0 种子数据渲染全部状态并截图；年点月环→月、月双击日期→日、日视图换天、切视角保留锚点，全部通

### M4 · 设置 + 收官

- 设置页（第三个 tab、顶部分组 chips 目录滚动 + scroll-spy、双态控件；默认值：时间片 45m / 连轴 90m / 空闲 5m / 软模式 / Alt+Q / 不置顶）
- 两主题（亮·极简暖 / 暗·工作台）整体打磨一遍；README（安装/运行/打包）；`docs/deviation.md` 收尾
- 最终交付：`pnpm tauri dev` 可跑、`pnpm tauri build` 出安装包（失败则交付 dev 可跑 + 打包排障记录）；`docs/screenshots/` 全套证据
